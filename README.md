# 🐉 ربات بازی رقص اژدهایان — نسخه‌ی شروع

این نسخه‌ی اولیه‌ی ربات (MVP) هست. شامل:
- ثبت‌نام بازیکن‌ها توسط ادمین
- نمایش داشبورد (منابع، سطح توسعه، ارتقای در حال انجام)
- تولید منابع به‌صورت خودکار با گذر زمان (۱ سال بازی = ۱ روز واقعی)
- ارتقای سطح منابع (چوب، سنگ، غذا، رعیت) با هزینه و زمان

> ⚠️ این فقط پایه‌ست. بقیه‌ی مکانیک‌های سند طراحی (جنگ، دیپلماسی، بازار، نامه، فروشگاه و...) رو بعداً قدم‌به‌قدم اضافه می‌کنیم.

---

## 📋 مرحله‌ی ۱: ساخت ربات در تلگرام

۱. تو تلگرام برو سراغ **@BotFather**
۲. دستور `/newbot` رو بفرست
۳. یه اسم و یه یوزرنیم بهش بده (یوزرنیم باید آخرش `bot` داشته باشه)
۴. BotFather یه **توکن** بهت میده (یه متن طولانی). این رو یه‌جا ذخیره کن و به کسی نده.

## 📋 مرحله‌ی ۲: گرفتن آیدی عددی خودت

۱. تو تلگرام به **@userinfobot** پیام بده
۲. یه عدد بهت میگه (مثل 123456789) — این آیدی عددیته
۳. این عدد رو تو فایل `config.py` جای `123456789` بذار

## 📋 مرحله‌ی ۳: آپلود کدها تو گیت‌هاب

۱. تو [github.com](https://github.com) یه حساب بساز (اگه نداری)
۲. روی **New repository** بزن، اسمش رو بذار (مثلاً `dance-bot`)
۳. گزینه‌ی **Private** رو بزن (که کسی کدت رو نبینه)
۴. تو صفحه‌ی ریپو، روی **uploading an existing file** بزن
۵. همه‌ی فایل‌های این پوشه رو بکش و رها کن (main.py, database.py, config.py, requirements.txt, Procfile, .gitignore, README.md)
۶. دکمه‌ی **Commit changes** رو بزن

## 📋 مرحله‌ی ۴: روشن‌کردن ربات آنلاین (با Railway)

۱. برو [railway.app](https://railway.app) و با حساب گیت‌هاب‌ات وارد شو
۲. روی **New Project** → **Deploy from GitHub repo** بزن
۳. ریپویی که ساختی رو انتخاب کن
۴. بعد از ساخته‌شدن پروژه، برو تب **Variables** و این رو اضافه کن:
   - اسم: `BOT_TOKEN`
   - مقدار: توکنی که از BotFather گرفتی
۵. Railway خودش ربات رو روشن می‌کنه (چند دقیقه صبر کن)

## 📋 مرحله‌ی ۵: ثبت‌نام اولین بازیکن

تو تلگرام، به رباتت پیام بده:

```
/register 123456789 استفون_بارثیون بارثیون استورمزاند leader
```

- عدد اول: آیدی عددی بازیکن
- اسم کاراکتر (به‌جای فاصله از `_` استفاده کن)
- اسم خاندان
- اسم قلعه
- `leader` (اختیاری): اگه رهبر خاندانه

بعد اون بازیکن می‌تونه `/start` و `/dashboard` رو بزنه.

---

## 🎮 دستورات

| دستور | کار |
|---|---|
| `/start` | شروع / دیدن آیدی عددی |
| `/dashboard` | دیدن منابع و وضعیت خاندان |
| `/upgrade wood` | ارتقای چوب (یا stone / food / population) |
| `/register ...` | فقط ادمین: ثبت‌نام یه بازیکن |

---

## ⚠️ نکته‌ی مهم درباره‌ی ذخیره‌ی اطلاعات

این نسخه از یه فایل دیتابیس ساده (`game.db`) استفاده می‌کنه. تو Railway، اگه ربات دوباره دیپلوی بشه ممکنه این فایل پاک بشه.
برای اینکه اطلاعات بازیکن‌ها همیشه بمونه، باید بعداً به **دیتابیس دائمی (مثل PostgreSQL)** مهاجرت کنیم — وقتی اون مرحله رسید بگو تا کمکت کنم.
